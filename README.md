# Run Aplikasi
untuk menjalankan aplikasi, yang harus di perhatikan adalah pastikan sudah menginstall flutter di komputer anda, dan pastikan juga sudah menginstall emulator android atau ios, jika sudah maka jalankan perintah berikut di terminal:

```bash
flutter pub get
flutter run
```

# keunggulan aplikasi
- menggunakan riverpod sebagai state management
- menggunakan dio sebagai http client jadi lebih ringan dan cepat
- tamplilan aplikasi yang simple dan mudah di pahami
